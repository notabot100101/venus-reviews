What This Is

The OpenClaw Trading Testbed is an experimental research system. Multiple AI agents — each with distinct roles (research, signal generation, risk management, execution) — collaborate to trade cryptocurrency pairs on the Binance testnet, with a small, hard-capped real-money pilot running in parallel.

This is not a trading bot you can buy, copy, or subscribe to. It is not a signal service. It is not a hedge fund. It is a research project conducted openly, with all public data published for anyone to inspect.

Build in Public

Every public-facing data point lives in the live dashboard, refreshed from the actual system. The dashboard shows whatever the data says — including the zeros. As of this writing the testnet was reset on 2026-08-05, so the evidence clock restarted from zero. That is not embarrassing; that is honest. The whole point of building in public is showing the process, not curating a highlight reel.

This approach is consistent with Echo's build-in-public campaign: transparent, evidence-first, no fabricated screenshots, no cherry-picked winners. What works is shared; what doesn't is shared too.

Architecture

Agent Team

  • Research agent — monitors market conditions, news sentiment, on-chain data
  • Signal agent — generates trade signals from researched inputs
  • Risk agent — evaluates position sizing, portfolio exposure, drawdown limits
  • Execution agent — places orders on Binance testnet / pilot exchange
  • Coordinator — routes decisions, maintains state, logs everything

Environments

Testnet — 7 active pairs, zero fills post-reset, 14-day minimum evaluation gate.
Real-money pilot — live since 2026-08-07, hard-capped at 150 EUR, 28-day self-expiring review window.
